**one unified dashboard**.

```

│   → lip-synced video                                               │
│                                                                    │
│   ─────────────────────────────────────────────────────────────    │
│   🔌 14 PROVIDERS  ·  🦙 OLLAMA LOCAL  ·  🖥️ HARDWARE DETECTION    │
│   🔑 ENCRYPTED KEYS  ·  ⚙️ AUTO MODEL ROUTING  ·  ∞ UNLIMITED      │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

### Why it exists

- ❌ Most AI tools: **one provider, one model, paid subscriptions**
- ✅ This studio: **any provider, auto-routes to the best free model, runs on your laptop**

### Core promises (real, never fake)

| Promise | How it's enforced |
|---|---|
| **No fake outputs** | Every result comes from a real API call; unsupported capability → honest error |
| **No fake progress** | Providers without progress → labelled "indeterminate" processing state |
| **No fake hardware info** | Browser limits reported truthfully; full data via optional local bridge |
| **No silent paid spend** | Paid providers default OFF; auto-routing skips them with a notice |
| **No plaintext keys** | AES-GCM encrypted at rest; only masked hints (`sk-••••••••1234`) shown |

## 8. 🖥️ AI Engine Setup & Model Manager

**Location:** sidebar → **AI Engine Setup** (`/engine`)

### 8.1 System check (real detection)

Click **"Check My System"** — it runs a genuine 10-step sequence:

```
 1. Detecting operating system      →  User-Agent client hints / bridge
 2. Detecting CPU                   →  hardwareConcurrency / bridge os.cpus()
 3. Detecting RAM                   →  deviceMemory / bridge os.totalmem()
 4. Detecting GPU                   →  WebGPU / WebGL / bridge nvidia-smi
 5. Detecting VRAM                  →  bridge only (browser can't)
 6. Checking disk space             →  storage quota / bridge statfs()
 7. Checking Ollama                 →  real GET /api/version
 8. Checking installed models       →  real GET /api/tags
 9. Detecting available providers   →  your connected credentials
10. Generating recommendations      →  rule engine on detected hardware
```

> **Honesty rule:** anything the browser *cannot* know is shown as "—" with a
> warning, never invented. Run the bridge for full fidelity.

### 8.2 Ollama control

- **Status card** — reachable / version / latency / installed models (all real)
- **Install** a model → streams **real byte-level progress** from `ollama pull`
- **Disk guard** — refuses to start if free space < model size
- **Test** — sends a real minimal request; vision models get a real image input
- **Remove** — real `DELETE /api/delete`

### 8.3 Recommendations

Ranked against your detected RAM/VRAM/disk:

| Tier | Meaning |
|---|---|
| 🏅 **Best** | Top quality your hardware can comfortably run |
| 👍 **Good** | Solid balance of speed & quality |
| 🧪 **Experimental** | May be slow / memory-tight — power users |

### 8.4 Diagnostics

**Run Full Diagnostics** tests every subsystem (System, Ollama, Providers, Models,
Storage, Queue) and reports ✓ Healthy / ⚠ Warning / ✕ Error with real reasons.

## 9. 🦙 Ollama Setup (Local Private AI)

| OS | Command / Link |

```bash
ollama serve                              # if not auto-started
curl http://127.0.0.1:11434/api/version   # should print {"version":"…"}
```

### Browser CORS (important)

The web app calls Ollama at `127.0.0.1:11434`. Allow the origin:

```bash
# Linux/macOS
OLLAMA_ORIGINS="*" ollama serve

# Windows (PowerShell)
$env:OLLAMA_ORIGINS="*"; ollama serve
```

**Or skip CORS entirely** by running the bridge (`node local-bridge.mjs`).

### Pull starter models

```bash
ollama pull llama3.2          # text (small)
ollama pull qwen3:4b          # text (mid)
ollama pull qwen2.5vl:7b      # vision (character analysis / image editor)
ollama pull moondream:1.8b    # tiny vision
```

### Cloud models & Claude

- `ollama signin` → unlocks ollama.com cloud-hosted models (auto-detected)
- **Claude is not on Ollama** — connect **OpenRouter** for Claude/GPT models

## 12. 💰 Credits System

This is a **local-first build**: usage is **unlimited** (∞) by default.

- The credit **engine is fully built** (reserve → commit → refund, mutex-locked,
  refund on failure/cancel) but every rule resolves to **0 credits** in unlimited mode.
- Admin can switch unlimited mode OFF in **Admin → Settings** to re-enable
  configurable pricing rules (task × provider × model × resolution × quality).

## 14. 🔐 Security

- **Passwords** — PBKDF2-SHA256 (60k iterations), per-user salt
- **API keys** — AES-GCM encrypted at rest; masked in UI; never logged
- **Sessions** — random 256-bit tokens, 7-day expiry, revocable
- **Authorization** — every row scoped to the owner; admin routes guarded
- **Uploads** — MIME + extension + size validated; random storage names
- **Credits** — server-side validation; concurrent requests can't double-spend
- **Bridge** — binds to `127.0.0.1` only; no secrets cross to it

## 15. 🖥️ Local Desktop Bridge (Real Hardware Access)

Browsers **cannot** read real CPU/GPU/VRAM/disk or control processes. Instead of
faking it, the app uses a proper bridge architecture:

```
  WEB FRONTEND  ──fetch──▶  local-bridge.mjs  ──▶  OS APIs  ──▶  OLLAMA
  (React)                   (127.0.0.1:8788)      node:os        /api/pull
                                                  nvidia-smi     /api/tags
                                                  statfs         /api/generate
```

```bash
node local-bridge.mjs     # zero dependencies, loopback-only
```

Endpoints: `/health` · `/system` · `/ollama/status` · `/ollama/pull` (streams real
progress) · `/ollama/delete`. See `LOCAL_AI_ARCHITECTURE.md`.

## 17. 🧯 Troubleshooting

| Symptom | Fix |
|---|---|
| Blank page | Hard-refresh (Ctrl+Shift+R). Boot is self-healing; should not stick. |
| Ollama "not reachable" | `ollama serve` with `OLLAMA_ORIGINS=*`, or run the bridge |
| Hardware shows "—" | Browser limit — run `node local-bridge.mjs` then re-check |
| Pull fails | Check disk space (guarded), verify `ollama pull <m>` works in terminal |
| No video provider | Video = cloud engines. Connect Replicate/Luma/NIM/HF (all free-tier) |
| Provider test fails | It's a real request — verify key/endpoint; never reports green falsely |

Full guide in `TROUBLESHOOTING.md`.

## 18. ⚠️ Known Limitations

- Full GPU VRAM / exact RAM / disk / process control need the optional bridge.
- Image/video *generation* requires a cloud engine (Ollama is text/vision-only).
- Replicate/Luma/NIM are server-side APIs; if a browser blocks them (CORS), the
  router honestly falls back to the next provider or simulator (if enabled).
- Free-tier video models can be slow; progress is shown honestly, never faked.
